# BoopLock

BoopLock is a simple Android security app that monitors failed device unlock attempts.

When an incorrect PIN, password, or pattern is detected, the app can automatically:

* Take photos using both front and back cameras
* Record video with audio
* Capture the device location (if possible)
* Send a notification about the failed unlock attempt
* Optionally send an email alert with collected data

The app is designed to work quietly in the background and help identify unauthorized access attempts.

## Features

* Failed unlock detection
* Front and rear camera capture
* Video recording with microphone audio
* GPS location capture
* Local notifications
* Optional email alerts
* Lightweight and privacy-focused
* No ads or tracking

## Requirements

* Android 8.0+
* Camera permission
* Microphone permission
* Location permission
* Notification permission
